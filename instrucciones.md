Quiero mejorar considerablemente la calidad visual de las ilustraciones y animaciones de mi calendario navideño.

Actualmente algunos personajes están siendo recreados , lo que provoca que sus cuerpos sean demasiado geométricos, sus ojos tengan movimientos extraños y las ilustraciones pierdan naturalidad.

Necesito que revises el enfoque actual y consideres integrar herramientas especializadas:

1. Rive para personajes y animaciones ilustradas interactivas.
2. GSAP para controlar secuencias, desplazamientos, rotaciones y transiciones.
4. Lottie para animaciones vectoriales previamente preparadas, cuando sea conveniente.

IMPORTANTE:

- No quiero personajes construidos mediante círculos, rectángulos tiesos
- No quiero ojos, rostros o extremidades animándose de manera independiente sin una intención artística.
- Los personajes deben conservar sus proporciones y apariencia
- Prioriza animaciones de personajes completos cuando se trate de ilustraciones rasterizadas.
- Utiliza animaciones individuales únicamente para elementos que realmente deban moverse.

Antes de implementar cambios, analiza la arquitectura actual y determina qué tecnología conviene para cada elemento.

Mantén la compatibilidad con HTML, CSS, JavaScript, Vite y GitHub Pages que es donde esta desplegado

No introduzcas backend, bases de datos ni servicios que requieran infraestructura adicional.

No reemplaces todo el proyecto. Mejora progresivamente los componentes visuales existentes y conserva las funcionalidades que ya funcionan.

Prioriza la calidad artística, la naturalidad de los movimientos y la coherencia de todas las ilustraciones con el estilo de collage navideño artesanal de nuestra referencia.
